🚀 How to Host This on GitHub Pages (Free)

  1. Create a GitHub Repository: Go to github.com/new and name it spent-tracker. Choose Public.
  2. Push this folder: Upload or git push all files in this project to the main branch.
  3. Enable GitHub Pages:
    • Open your repository on GitHub → click Settings.
    • Click Pages in the left sidebar menu.
    • Under Build and deployment > Branch, choose main and / (root), then click Save.
  4. Live URL: Within 1-2 minutes, your website is live at https://<username>.github.io/spent-tracker/!
